Antes de elegir tu conexión

Respuestas para entender el servicio y preparar tu consulta.

¿Necesito conexión IP para utilizarla?
Sí, la telefonía IP transmite la voz mediante paquetes de datos digitales a través de redes locales (LAN) o enlaces de Internet dedicados corporativos, garantizando baja latencia y alta claridad.
¿Es posible transferir llamadas?
Totalmente. Es una de las funciones centrales de la plataforma: permite transferir de forma directa o supervisada entre anexos físicos, terminales móviles y sedes remotas interconectadas.
¿Se pueden atender varias llamadas al mismo tiempo?
Sí. La capacidad de concurrencia de llamadas simultáneas (canales SIP truncales) se dimensiona a la medida de tu flujo de atención, evitando saturaciones o tonos de ocupado para tus clientes.
