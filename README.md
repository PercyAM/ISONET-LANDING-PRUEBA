# ISONet Perú — propuesta profesional

Landing page estática para revisión. GitHub Pages sirve este proyecto sin proceso de compilación.

- Inicio: `index.html` redirige a `ISONet_Propuesta_Profesional/index.html`.
- Páginas: propuesta principal y soluciones de línea dedicada simétrica, transporte de datos, internet satelital, telefonía IP y enlaces digitales de doble vía.
- Recursos: imágenes, logotipos, mapa, estilos y scripts están incluidos con sus rutas relativas.
- Requiere conexión a Internet para Google Fonts y enlaces externos (WhatsApp, correo, teléfono y acreditaciones).
